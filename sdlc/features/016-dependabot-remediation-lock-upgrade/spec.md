## Summary

This change upgrades or removes the alerted transitive packages in `uv.lock` by updating exactly two `pyproject.toml` declarations and regenerating the lock. It adds `tests/test_dependency_floors.py` so maintainers and security reviewers can verify the approved version floors, Python floor, and MarkItDown extras without changing application behaviour.
